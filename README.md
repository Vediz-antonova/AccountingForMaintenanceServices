# МойАвтосервис

Мобильное приложение для учёта технического обслуживания автомобилей. Помогает отслеживать расходы на обслуживание, напоминает о плановом ТО и упрощает управление данными об автомобилях.

## Стек технологий

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Архитектура:** MVVM (ViewModel + StateFlow)
- **Навигация:** Navigation Compose
- **Сборка:** Gradle (Kotlin DSL)
- **Минимальная версия Android:** API 24 (Android 7.0)

## Структура проекта

```
app/src/main/java/com/vedizl/accountingformaintenanceservices/
├── data/
│   ├── model/          # Модели данных (Car, CarMake)
│   └── repository/     # Репозитории (CarRepository)
├── ui/
│   ├── theme/          # Тема приложения (цвета, типографика)
│   ├── cars/           # Экраны управления автомобилями
│   ├── history/        # Экран истории обслуживания
│   └── navigation/     # Навигация (NavGraph)
└── MainActivity.kt     # Главная активность
```

## Функциональность (текущая версия)

### Этап 1: Управление автомобилями
- Добавление автомобиля с выбором марки, модели и года выпуска из предопределённых списков
- Ввод государственного номера в формате `1234AB1`
- Просмотр списка добавленных автомобилей
- Удаление автомобиля с подтверждением
- Выбор автомобиля для просмотра истории обслуживания (заглушка)

## Установка и запуск

1. **Клонировать репозиторий:**
   ```bash
   git clone <url-репозитория>
   ```

2. **Открыть проект в IntelliJ IDEA:**
   - File → Open → выбрать папку проекта
   - Дождаться синхронизации Gradle

3. **Запуск:**
   - Подключить устройство Android через USB или запустить эмулятор
   - Выбрать конфигурацию `app` и нажать Run
