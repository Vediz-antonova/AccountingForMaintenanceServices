# МойАвтосервис

Мобильное приложение для учёта технического обслуживания автомобилей. Позволяет вести историю обслуживания, отслеживать расходы на запчасти, фильтровать записи по категориям, видам работ и датам, а также управлять несколькими автомобилями.

Приложение предназначено для автомобилистов, которые хотят систематизировать информацию о ремонте и обслуживании своих машин: какие работы выполнялись, когда, с каким пробегом, какие запчасти использовались, сколько они стоили и кто их производитель.

## Стек технологий

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Архитектура:** MVVM (ViewModel + StateFlow)
- **Навигация:** Navigation Compose
- **База данных:** Room (SQLite)
- **Сборка:** Gradle (Kotlin DSL)
- **Минимальная версия Android:** API 24 (Android 7.0)

## Функциональность

### Управление автомобилями
- Добавление автомобиля с выбором марки, модели и года выпуска (включая российские бренды)
- Ввод и редактирование государственного номера прямо из карточки автомобиля
- Просмотр списка автомобилей, выбор активного автомобиля
- Удаление автомобиля с каскадным удалением всех связанных записей об обслуживании

### Записи об обслуживании
- Создание записи с указанием категории, вида работы, даты и пробега
- Поддержка информации о запчастях: артикул, производитель, стоимость в рублях
- Примечания к каждой записи
- Категории работ: Двигатель, Трансмиссия, Тормозная система, Шины, Подвеска, Охлаждение, Электрика, Кузов — каждая с предопределённым набором видов работ
- Возможность ввести свою категорию или вид работы 
- Редактирование и удаление записей
- Фильтрация списка по категории, виду работы и диапазону дат
- Просмотр детальной информации о записи
